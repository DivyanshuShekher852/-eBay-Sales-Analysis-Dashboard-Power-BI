# 🛒 eBay Sales Analysis Dashboard | Power BI

## 📌 Project Overview

The **eBay Sales Analysis Dashboard** is an interactive Business Intelligence project built using **Microsoft Power BI**. The dashboard transforms raw e-commerce sales data into meaningful insights that help businesses monitor performance, identify trends, and make data-driven decisions.

This project demonstrates skills in **data cleaning, data modeling, DAX, data visualization, and business analytics**.

---

## 🎯 Business Problem

E-commerce businesses generate thousands of transactions every day, making it difficult to track performance using spreadsheets alone.

This dashboard helps answer key business questions such as:

* Which products generate the highest sales?
* Which categories perform the best?
* Which regions contribute the most revenue?
* How are sales changing over time?
* Which shipping methods are most frequently used?
* What are the key performance indicators (KPIs) of the business?
